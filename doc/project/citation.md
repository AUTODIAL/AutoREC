# Citation and references

If AutoREC contributes to published work, cite the current AutoREC preprint:

> Ali Jaberi, Yonatan Kurniawan, et al. *AutoREC: A reinforcement learning
> platform for equivalent circuit model generation*. arXiv:2604.27266 (2026).

The authoritative title, author list, revision history, and downloadable formats
are available on [arXiv](https://arxiv.org/abs/2604.27266). The persistent
arXiv-issued DOI is
[10.48550/arXiv.2604.27266](https://doi.org/10.48550/arXiv.2604.27266).

```bibtex
@misc{jaberi2026autorec,
  title         = {AutoREC: A reinforcement learning platform for equivalent
                   circuit model generation},
  author        = {Jaberi, Ali and Kurniawan, Yonatan and others},
  year          = {2026},
  eprint        = {2604.27266},
  archivePrefix = {arXiv},
  primaryClass  = {cs.LG},
  doi           = {10.48550/arXiv.2604.27266}
}
```

Check the arXiv record before submission in case the paper metadata or
recommended citation has been revised. Cite the exact AutoREC software version
or commit used in the methods and archive experiment configurations, datasets,
and model artifacts needed to interpret the result.
